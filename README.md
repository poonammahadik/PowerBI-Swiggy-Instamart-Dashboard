

# Swiggy Instamart Sales Analysis Dashboard

An interactive Power BI dashboard built to analyze the sales 
performance, order trends, and customer ratings of 
Swiggy Instamart across multiple years and city tiers.

## Dashboard Highlights
- **Total Sales:** 1.20M
- **Total Orders:** 9K
- **Average Sales:** 141.01
- **Average Rating:** 3.92

## Features
- KPI cards for quick performance overview
- Sales breakdown by Shop City Type (Tier 1, 2, 3)
- Category-wise sales analysis (Fruits, Snacks, Dairy, etc.)
- Sales distribution by Shop Size (Small, Medium, High)
- Year-wise order trends (2021–2024)
- Dynamic slicers and filters for interactive exploration

## Tools Used
Power BI Desktop

## Skills Demonstrated
Data Visualization, DAX Measures, KPI Design, 
Slicers & Filters, Business Insights
